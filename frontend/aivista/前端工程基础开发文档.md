# AiVista 前端工程基础开发文档

> 对应迭代：前端迭代 0——工程基础
> 当前状态：已完成
> 维护规则：本文记录工程运行、通用架构、请求、认证和联调约定；通用能力变化时必须同步修改。

## 1. 项目入口与常用命令

在 `frontend/aivista` 目录执行：

```powershell
pnpm dev
pnpm lint
pnpm build
pnpm start
```

PowerShell 执行策略阻止 `pnpm` 时使用 `pnpm.cmd`。开发服务默认地址为 `http://localhost:3000`。

## 2. 基础能力

| 范畴 | 当前约定 |
| --- | --- |
| 框架与样式 | Next.js App Router、TypeScript、Tailwind CSS、shadcn/ui。 |
| 数据与表单 | TanStack Query 管理浏览器端服务端状态与内存缓存；正式表单使用 React Hook Form + Zod，`@hookform/resolvers/zod` 连接两者。 |
| 请求与类型 | Axios 处理浏览器请求；接口 DTO 在 feature API 层映射为领域模型。 |
| 本地状态 | 认证内部使用 Zustand；页面只消费稳定的 `useSession` 等接口。 |
| 测试 | Vitest + React Testing Library 做组件/交互单元测试；`pnpm test` 单次运行、`pnpm test:watch` 监听；配置见 `vitest.config.mts` 与 `vitest.setup.ts`，测试文件与被测模块同目录命名 `*.test.tsx`。后续按需引入 Playwright。 |
| 主题 | 使用语义 token，如 `bg-background`、`text-foreground`、`bg-card`；颜色实际值由 `globals.css` 集中管理。 |

## 3. 工程结构与关键代码位置

```text
src/
├── app/       # App Router 路由与页面组合
├── widgets/   # 跨页面完整界面区块
├── features/  # 业务能力：api、model、ui、lib
├── entities/  # 前端领域模型
├── shared/    # HTTP、通用 UI、工具与配置
├── components/# 已有 shadcn/ui 与待迁移展示组件
└── lib/       # 现有通用工具，按需迁入 shared/lib
```

依赖方向固定为 `app → widgets → features → entities → shared`，同层业务功能不直接互相导入。所有资源 ID 使用字符串；用户模型区分 `CurrentUser` 与 `PublicUser`，不新增万能 `User` 类型。

`QueryProvider` 位于 `src/shared/api/query-provider.tsx` 并在根布局接入。Query 缓存仅保存浏览器内存中的服务端响应；业务请求统一在 feature 的 `api` 层将 DTO 映射为领域模型。页面局部交互使用组件状态，认证继续使用 Zustand，不在 Zustand 镜像接口响应。
会话进入 `anonymous` 时清空 Query 缓存，避免同一浏览器后续登录其他账户时复用私有数据或签名 URL。

## 4. 通用开发约定

- 页面和 UI 只使用领域模型；`shared/api` 只处理 HTTP 与统一响应。
- 浏览器请求只使用 `/api/*` 相对路径，不在业务代码写 Spring Boot 地址。
- 私有签名 URL 仅保存在 SPA 内存；不得写入持久化存储、URL、日志、埋点或错误监控。页面使用 `Referrer-Policy: no-referrer`。
- 公开页面优先 SSR/静态生成；已登录业务页以客户端请求为主。

## 5. 配置与环境

开发环境中，普通 REST 请求由 Next.js rewrite 转发到 `BACKEND_ORIGIN`；`GET /api/events` 例外，由 `src/app/api/events/route.ts` 专用 Route Handler 转发 Bearer Token 和后端 SSE 响应流。两条开发链路默认使用 `http://localhost:8888`，配置值不带 `/api` 后缀。复制 `.env.example` 为 `.env.local` 覆盖本地地址，`.env.local` 不提交。

认证成功后，每个浏览器标签页维持一条用户级 SSE 连接，承载生成任务状态、官方消息及后续互动等轻量事件；REST 仍负责所有读写和断线后的快照对账。标签页不可见时不主动关闭连接；浏览器或系统挂起、网络恢复或页面重新可见后重新连接并对账。生成提交前的 `ensureReady()` 只校验该事件流已完成握手和快照对账，不替代服务端任务状态。

生产环境浏览器仍只使用同源 `/api/*`，但请求不经过 Next rewrite 或 Route Handler：规划由 Nginx 将 `/api/` 直接代理到 Spring Boot，并为 `/api/events` 关闭响应缓冲、缓存和压缩，保留认证 Header，设置长读取超时。当前处于开发阶段，本仓库暂不提供或启用生产 Nginx 配置，正式部署时另行实现并验证。

## 6. 认证、请求与联调

- Access Token 仅保留在内存，请求使用 `Authorization: Bearer <accessToken>`。
- Refresh Token 由 HttpOnly Cookie 管理。收到 `40100` 时，全局 Axios 拦截器执行唯一 Single Flight 刷新并重放原请求；刷新接口返回 `40102` 才清除会话。
- 浏览器完整刷新后，`SessionProvider` 只请求 `GET /api/users/me`；不得绕过拦截器直接调用刷新接口。
- 网络、超时或服务端异常保留当前登录状态并提供重新连接；匿名受保护路由由 `AppShell` 返回首页。
- 认证具体契约以 [后端用户模块](../../backend/aivista/用户模块.md) 为准。
