# AiVista 生成工作台模块

> 对应迭代：前端迭代 2——生成工作台
> 当前状态：实施中
> 维护规则：本文记录普通图像生成与 Agent 创作的页面交互、任务状态和接口消费；代码、测试、接口契约或交互规则变化时必须同步修改。

## 1. 目标与范围

接入已完成的普通文生图、图生图与 Agent 后端闭环，使已登录用户能创建或选择会话、选择创作模式、提交任务、实时查看状态并管理成功图片。

当前不包含局部重绘；普通模式与 Agent 模式的生成结果共同复用资产删除、收藏、发布和详情能力。

后端业务事实与接口契约以 [图像生成任务模块.md](../../backend/aivista/图像生成任务模块.md) 为准。

## 2. 已确认约束

- 接入普通文生图与最多 3 张参考图的图生图；`imageCount` 为 `1`～`6`，服务端是最终校验方。
- Agent 模式向 `/agent-creations` 提交 `sessionId`、prompt、最多 3 个授权图片 ID，以及可选的画幅与目标数量约束。画幅默认 `AUTO`，数量默认 `0`（自动）；用户可固定支持的比例和 `1`～`6` 张。Agent 不提交 promptExtend 或 negativePrompt；前者由 Tool 固定为 true，后者由模型按需填写。
- Agent 模式不显示额外说明文案；模式选择、参考图和创作输入保持在同一 Composer 中。
- 同一会话同一时刻只允许一个 `RUNNING/WAITING_INPUT` Creation。前端根据会话快照禁用 Composer，Java 在锁定会话后再次校验并返回 `40908`，因此并发请求不能绕过限制；不同会话仍遵循用户级图片任务并发上限。
- 进入页面加载会话列表。首次使用展示不在列表中的空白创作框；首次成功提交不传 `sessionId`，以后端 `202 Accepted` 返回的 `sessionId` 建立当前会话。
- 顶部当前会话标题与左侧会话列表统一最多展示 10 个字符，超出后追加 `...`；持久化标题保持完整，悬停可查看原始标题。
- 空白创作框成功提交前不允许再开启新的空白会话；同一会话有未完成任务时禁用再次提交。
- 提交期间按钮立即禁用；创建响应不确定时重新读取会话快照，不在浏览器保存或自动重放 POST。
- 用户最多四个未完成任务，每日最多请求 12 张；前端负责提示，后端负责最终限制。
- 同一会话只归类连续创作记录，不自动拼接或继承历史提示词；每次普通生成只使用本轮输入。
- 注册、登录或会话恢复时统一确认用户协议与第三方数据处理规则；生成页面不再单独弹出同意流程。
- 结果只展示成功转存图片；失败不展示虚构图片占位。普通图像生成不提供取消状态或取消操作。
- `RUNNING` 与 `WAITING_INPUT` Agent Creation 都显示“停止”；取消由 Java权威事务提交，SSE `RUN_CANCELLED` 清理实时投影，再以 REST 快照显示最终 `CANCELLED`。
- Agent 运行中的文字、Skill 和 Tool 来自 SSE；数据库只保存 Loop 结束时提交的最终 Activity。SSE 新建或重连时使用 `RUN_SNAPSHOT` 恢复 Java 内存中的安全实时投影。
- Agent 调用 `request_user_input` 后，表单卡片独立显示在“创作过程”下方、最终回复上方。卡片复用全局暖白表面、浅杏选中态、近黑确认按钮与陶土焦点样式，不形成独立主题。表单 Schema V2 的每个字段只有一个字符串 `value`；前端克隆完整表单作为本地草稿，只修改 `fields[].value`，必填为空时禁止确认，提交时发送填写后的完整 `form`，跳过时发送 `form: null`。`FORM_REQUESTED/FORM_RESOLVED` 直接携带完整持久快照并更新缓存，不为每个事件额外请求 REST；刷新、重进页面或 SSE 重连时才从 Turn 快照恢复。用户可以确认、跳过，或直接“取消本次创作”；取消复用 Creation 取消接口，REST 快照会把尚未处理的表单恢复为 `CANCELLED`。
- 收到 Agent `RUN_STARTED` 时立即重新读取对应会话的 Creation 外壳，避免实时文本先到而页面尚无可挂载轮次；收到终态事件时先完成 REST 快照对账，再清除瞬时文本投影，避免最终内容闪烁或只在结束后一次出现。
- 会话首次进入时定位到底部；内容增长期间自动跟随。用户主动上滑并超过底部阈值后暂停跟随并显示“回到底部”，点击后恢复。上滑还会将 Composer 收为较窄的单行形态并主动让文本框失焦；再次点击文本框重新展开，因此收起/展开可重复触发。

| --- | --- | --- | --- |
| 状态真相 | SSE 负责主要实时更新；会话列表与当前创作轮次的 REST 快照是页面权威数据。 | SSE 不支持事件回放且可能断开。 | 进入生成页、SSE 首连或重连后刷新会话列表；当前 URL 有 `sessionId` 时同时刷新该会话轮次。事件立即更新已加载轮次的最小状态，再请求当前会话快照取得完整结果。 |

| 签名 URL | 仅内存缓存至过期时间。 | 私有 URL 不能持久化。 | 临近过期或已过期时重新查询。 |

## 5. 页面、路由与交互设计

路由为 `/generate`，仅认证用户可访问。URL 只接受可选的 `sessionId`，不使用 `taskId`：创作轮次接口已经包含关联任务快照。页面左侧始终展示会话列表；无 `sessionId` 时右侧为新绘画状态，居中展示生成输入区；选择历史会话或创建任务成功并获得 `sessionId` 后，右侧切换为会话工作区，上方滚动展示历史内容，下方固定生成输入区。移动端须保证会话切换、提交和结果查看可达。

每个 `GenerationTurn` 对应一个 `CreationTask`，包含真实的 USER/ASSISTANT 消息和一个普通生成任务快照。用户正向提示词和可选负向提示词显示为输入气泡；AI 回复区显示排队、处理、模型重试、失败、终态数量和生成图片。

| 场景 | 前端行为 |
| --- | --- |
| 登录/恢复 | 登录后建立并维持 SSE；收到 ready 后进入 READY。进入生成页时读取会话列表，URL 带 `sessionId` 时读取该会话的创作轮次；SSE 首连或重连完成后刷新这些页面快照。 |
| 创建任务 | 校验输入；全局用户协议确认完成且 SSE READY 后才发送 POST；`202` 后使会话列表缓存失效并跳转至携带 `sessionId` 的会话页，由页面读取会话列表和创作轮次，显示已创建的排队任务。 |
| 活动任务 | `QUEUED` 显示排队；`GENERATING` 显示“正在生成图片”；`SAVING` 显示“正在保存图片”且图片列表为空；带重试计数的 `QUEUED` 显示模型重试 `n/3`。 |
| 终态任务 | 成功、部分成功、失败分别显示后端数量和安全错误提示；只显示成功图片。 |
| 无数据/网络错误 | 提供明确空状态、重试和重新连接；不清空已有内存结果。 |

## 6. API、前端模型与状态管理

| 目的 | 接口 | 前端约定 |
| --- | --- | --- |
| 用户协议 | `GET /api/policies/user-agreement`、`POST /api/users/me/consents/user-agreement` | 由全局认证流程展示；生成页面只消费其已确认状态。 |
| 创建普通任务 | `POST /api/generation-tasks` | 不带客户端幂等键；`202` 后仅以返回的 `sessionId` 跳转，并刷新该会话创作轮次。 |
| 创建/取消 Agent | `POST /api/agent-creations`、`POST /api/agent-creations/{creationId}/cancel` | 创建与普通模式都以会话快照恢复；取消对 `RUNNING/WAITING_INPUT` Agent 展示，重复取消返回当前终态。 |
| 响应 Agent 表单 | `PUT /api/agent-creations/{creationId}/forms/{formId}/response` | `action` 为 `SUBMIT/SKIP`；`SUBMIT` 携带填写后的完整 `form`，`SKIP` 携带 `form: null`。响应直接更新当前表单，后续 `FORM_RESOLVED` 可幂等覆盖。 |
| 任务详情 | `GET /api/generation-tasks/{generationTaskId}` | 任务详情保留为单任务权威快照接口，但不参与全局 SSE 对账。 |
| 会话与创作轮次 | `GET /api/generation-sessions`、`GET /api/generation-sessions/{sessionId}/turns`、`PATCH /api/generation-sessions/{sessionId}` | 会话侧栏不返回图片；接口按创作轮次游标每页最多 5 项加载，每项包含 `mode`、USER/ASSISTANT 消息及生成快照。 |
| 实时信号 | `GET /api/events` | Header 带 Bearer Token，不将 Token 放入 URL；开发环境由 `src/app/api/events/route.ts` 流式转发，生产环境由 Nginx 直接代理到 Spring Boot。 |

每个浏览器标签页最多维护一条认证用户级 SSE；多个会话和最多四个并行任务复用同一条连接，不随生成页或会话切换而重复建立。连接建立或断开后会持续自动重试：首次约等待 500ms，之后约 1s、2s，最大间隔为 3s；手动重试会重置计数。创建任务仍以 SSE READY 为门禁，等待上限为 10 秒，超时则不发送 POST。进入生成页时读取会话列表；当前 URL 带 `sessionId` 时读取对应创作轮次。每次 SSE 首连或重连完成后，生成页重新请求会话列表及当前会话轮次；Agent 运行中还可收到 `RUN_SNAPSHOT` 恢复文字、Skill 和 Tool 投影。收到任务事件时先按 `revision` 更新已加载会话轮次中的生成状态与模型重试进度，再刷新已打开的会话列表；若事件属于当前会话，则立即刷新其轮次快照以取得完整结果和图片。成功或部分成功事件会使活跃资产列表失效并重新请求。同 revision 的 REST 可补全数据，旧快照不得覆盖新事件。

表单事件与普通瞬时 Agent 事件不同：Java只在表单事务提交后发布完整快照，`streamId` 以 `formId` 隔离连续表单。前端按 Creation revision 合并，旧 REST 不得覆盖更新的表单状态。表单提交恢复的新 Pi 分段使用新的实时 stream，但保留表单前已经显示的安全阶段说明，随后继续追加文字和 Tool 状态。

## 8. 异常场景、可靠性与安全

- `40100` 交由全局认证拦截器刷新并重放；`40102` 按工程基础文档清理会话。
- `409` 的活动任务或同意规则冲突必须展示可行动提示；`429` 提示稍后重试；`50000` 系统繁忙时提供稍后重试。
- 任务结果、SSE 和签名 URL不得写入持久化存储、埋点或错误监控。图片页设置 `Referrer-Policy: no-referrer`。
- 会话中的任一已使用签名 URL 临近到期或图片加载失败时回查轮次快照；终态任务图片统一使用图片 DTO，当前网格只渲染 `imageUrls.thumbnail`，点击卡片即复用 `display` 打开资产详情。详情上下箭头按当前已加载会话图片顺序切换；切到最早已加载图片且仍有更早轮次时，先加载更早一页再继续。悬停操作提供下载原图、复制展示图及收藏/发布/删除；原图仅在下载时按作者归属申请。已删除图片仍保留 DTO 和 `sourceIndex`，但两种 URL 均为 `null`，前端显示删除占位。
- 前端不得自动重放创建 POST、自行拼接历史提示词、传服务商参数或推断任务终态。
- SSE 初次连接与断线后均会持续自动重连，重连间隔最大为 3 秒；提交前等待 SSE READY 最多 10 秒，超时则不发送创建请求。任务一旦创建，后端执行不依赖浏览器连接，重连后通过快照恢复。

## 11. Agent 会话结果展示

- 数据层保持真实执行语义：一次 Agent Creation 可以包含多个 `generation_tasks`；不同最终提示词继续分别落在对应任务与资产中。
- 展示层按 Creation 聚合所有任务结果，只显示一次图片完成总数，并将本轮全部图片放在同一条可横向滚动的图片行中，不重复输出每个任务的“完成 1 张”。
- Agent 图片进度统一显示为 `（已完成数/本轮总数）图片生成中…` 或 `（总数/总数）图片已生成`；不逐条展示重复的“文生图已完成”。
- 图片总数只汇总已经创建的 Generation Task 的 `requestedImageCount`；被 Harness 拒绝的 Tool 尝试、重试次数以及 `inspect_image` 等非生成 Tool 不参与计数。生成任务尚未进入权威快照前不猜测数字进度。
- Agent 用户消息单独显示在右侧，回复卡片显示在左侧；普通图片生成不使用 Agent 对话布局，用户提示词直接作为左侧结果卡片的主要文本。
- 回复卡片右上状态标签在真正执行期间显示主题色旋转图标：Agent 的 `RUNNING`，以及普通任务的 `QUEUED/GENERATING/SAVING`。`WAITING_INPUT` 已暂停等待用户，不显示旋转图标；成功、失败和取消等终态同样不显示。
- Agent 的 Skill、阶段说明与 Tool 生命周期统一收进“创作过程”，运行时默认展开，完成后允许展开或收起；这里只展示安全的阶段说明，不展示模型隐藏思维链。阶段说明直接使用正文排版，不为每一步重复添加完成对勾；Skill 使用灰色工具图标与“已加载技能：名称”，图片 Tool 使用单条图标化聚合进度。
