# AiVista 生成工作台模块

> 对应迭代：前端迭代 2——生成工作台
> 当前状态：设计中
> 维护规则：本文记录普通文生图的页面交互、任务状态和接口消费；代码、测试、接口契约或交互规则变化时必须同步修改。

## 1. 目标与范围

接入已完成的普通文生图后端闭环，使已登录用户能创建或选择会话、确认第三方处理规则、提交任务、实时查看状态、取消任务并查看成功图片。

本迭代不包含局部重绘、会话或图片删除、收藏、发布和社区展示。

后端业务事实与接口契约以 [图像生成任务模块.md](../../backend/aivista/图像生成任务模块.md) 为准。

## 2. 已确认约束

- 仅接入普通文生图；`imageCount` 为 `1`～`6`，服务端是最终校验方。
- 进入页面加载会话列表。首次使用展示不在列表中的空白创作框；首次成功提交不传 `sessionId`，以后端 `202 Accepted` 返回的 `sessionId` 建立当前会话。
- 空白创作框成功提交前不允许再开启新的空白会话；同一会话有未完成任务时禁用再次提交。
- 每次用户主动提交生成新的 UUID v4 幂等键；重复点击、超时和网络重试复用原键。
- 用户最多四个未完成任务，每日最多请求 12 张；前端负责提示，后端负责最终限制。
- 同一会话会继承历史提示词。工作台必须提示用户：一个会话只围绕一个主题创作，更换主题时新建会话。
- 首次生成或规则版本升级时，用户必须阅读并确认第三方数据处理规则。
- 结果只展示成功转存图片；取消和失败不展示虚构图片占位。

## 3. 关键决策记录

| 决策事项 | 最终结论 | 原因与取舍 | 对实现的影响 |
| --- | --- | --- | --- |
| 状态真相 | REST 任务详情和会话消息为权威状态；SSE 只作刷新信号。 | SSE 不支持事件回放且可能断开。 | 首次进入、重连及终态事件后均重新查询。 |
| 会话创建 | 首次提交原子创建会话与任务。 | 避免产生空会话和额外创建接口。 | 空白创作框不传 `sessionId`。 |
| 签名 URL | 仅内存缓存至过期时间。 | 私有 URL 不能持久化。 | 临近过期或已过期时重新查询。 |
| 取消反馈 | 调用开始前显示已取消；调用开始后显示取消处理中，最终仍以服务端快照为准。 | 百炼同步调用不能被前端直接中断。 | 取消后不展示迟到结果。 |

## 5. 页面、路由与交互设计

路由为 `/generate`，仅认证用户可访问。页面至少包含会话列表、当前会话消息/结果区和生成输入区；移动端须保证会话切换、提交、取消和结果查看可达。

| 场景 | 前端行为 |
| --- | --- |
| 首次进入/重连 | 查询会话列表和当前会话消息；无会话时展示空白创作框。 |
| 创建任务 | 校验输入、确认同意规则、生成或复用幂等键，提交后按 `202` 快照显示排队。 |
| 活动任务 | 显示 `QUEUED`/`RUNNING` 状态和取消入口；同会话禁用提交。 |
| 终态任务 | 成功、部分成功、失败、取消分别显示后端数量和安全错误提示；只显示成功图片。 |
| 取消 | 提交取消请求；等待权威快照收敛，不按本地猜测覆盖更高 `taskVersion`。 |
| 无数据/网络错误 | 提供明确空状态、重试和重新连接；不清空已有内存结果。 |

## 6. API、前端模型与状态管理

| 目的 | 接口 | 前端约定 |
| --- | --- | --- |
| 同意规则 | `GET/POST /api/users/me/consents/generation` | 展示服务端完整文案，仅回传已展示的 `policyVersion`。 |
| 创建任务 | `POST /api/generation-tasks` | 必带 `Idempotency-Key`；`202` 后使用任务概要更新本地状态。 |
| 任务详情/取消 | `GET /api/generation-tasks/{taskId}`、`POST /api/generation-tasks/{taskId}/cancel` | 详情为权威快照，取消后回查。 |
| 会话与消息 | `GET /api/generation-sessions`、`GET /api/generation-sessions/{sessionId}/messages`、`PATCH /api/generation-sessions/{sessionId}` | 使用后端游标分页，不伪造总数。 |
| 实时信号 | `GET /api/events` | Fetch 流式 SSE，Header 带 Bearer Token，不将 Token 放入 URL。 |

SSE 收到事件时仅接受更大的 `taskVersion`，随后查询详情。离开生成页主动关闭连接，不取消任务；单页最多一条连接，遵守后端单用户三条连接上限。

## 8. 异常场景、可靠性与安全

- `40100` 交由全局认证拦截器刷新并重放；`40102` 按工程基础文档清理会话。
- `409` 的活动任务、幂等键或同意规则冲突必须展示可行动提示；`429` 有 `Retry-After` 时展示可重试时间；`503` 提供稍后重试。
- 任务结果、SSE 和签名 URL不得写入持久化存储、埋点或错误监控。图片页设置 `Referrer-Policy: no-referrer`。
- 网络重试必须复用原幂等键；前端不得自行拼接历史提示词、传服务商参数或推断任务终态。
