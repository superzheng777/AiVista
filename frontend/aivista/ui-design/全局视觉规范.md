# AiVista 全局视觉规范

> 适用范围：AiVista Web 前端的应用壳层、灵感、生成、资产、作者主页及其共用组件
> 当前状态：已生效
> 维护规则：本文件定义跨页面的视觉令牌和主题边界。新增或调整全局颜色、主题能力、共用表面或导航配色时，必须与 `src/app/globals.css` 同步；页面自身的布局、尺寸和业务交互仍记录在对应页面设计文档。

## 1. 目标与边界

全站使用单一的暖色编辑排版视觉体系：米白页面底色、暖白功能表面、浅杏色状态背景、近黑文字和少量陶土橙强调。该体系用于统一应用壳层与所有业务页面，不能由单个页面覆盖为另一套主题。

本规范不定义成功、提示、警告等状态色；这些状态仍使用各组件现有语义色，后续如需统一应另行确认具体色值和无障碍对比度。

## 2. 主题策略

- 产品当前只提供固定浅色主题，不再提供深色、跟随系统或主题切换入口。
- `html`、`body` 和各业务页面均以 `--page-bg` 作为页面底色；功能容器、导航、卡片和输入框以 `--surface-bg` 为主表面。
- 不再读取、写入或依赖浏览器内的主题偏好。用户浏览器中旧的主题偏好键即使存在，也不影响页面呈现。

## 3. 核心视觉令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page-bg` | `#F5F0E6` | 所有页面最外层背景。 |
| `--surface-bg` | `#FFFDF7` | 菜单栏、卡片、输入框和主要容器背景。 |
| `--active-bg` | `#F7E3D4` | 导航、会话等选中状态和浅色状态背景。 |
| `--primary` | `#171612` | 一级文字、黑色主按钮和关键图标。 |
| `--text-secondary` | `#716B61` | 次级文字、默认导航文字和辅助图标。 |
| `--accent` | `#C95F3F` | 品牌强调、有限的主要操作、装饰方块和焦点环。 |
| `--border` | `#D9CFBF` | 边框与分隔线。 |

补充令牌由核心令牌扩展而来：`--surface-soft`、`--surface-hover`、`--text-muted`、`--accent-hover`、`--accent-soft`、`--peach`、`--border-strong`。遮罩、阴影、骨架屏、占位文字和装饰色也在 `src/app/globals.css` 集中定义，业务组件不得重新写入十六进制色值。

`--secondary` 是既有 shadcn/Tailwind 的“次级表面”语义，映射至 `--surface-soft`；它不是“次要文字”令牌。次要文字必须使用 `--text-secondary`，避免语义冲突。

## 4. 应用壳层

| 区域/状态 | 令牌 | 实际颜色 |
| --- | --- | --- |
| 菜单栏背景 | `--surface-bg` | `#FFFDF7` |
| 菜单栏右侧分隔线 | `--border` | `#D9CFBF` |
| 默认导航文字与图标 | `--text-secondary` | `#716B61` |
| 导航悬浮背景 | `--surface-hover` | `#FAF0E4` |
| 导航选中背景 | `--active-bg` | `#F7E3D4` |
| 选中导航文字与图标 | `--primary` | `#171612` |
| 主要操作/小型强调 | `--accent` | `#C95F3F` |

桌面端保留固定 88px 左侧导航，移动端保留既有底部导航行为。两者均由应用壳层消费同一套令牌，不在业务页面复制导航配色。

## 5. 实现约束与位置

- 令牌唯一来源：[globals.css](../src/app/globals.css)。它同时把视觉令牌映射到现有 shadcn/Tailwind 的 `background`、`card`、`popover`、`sidebar` 等语义令牌，避免破坏已有基础组件。
- 页面和共用组件通过 `var(--...)` 或已有语义 Tailwind 类消费令牌；截至本次同步，`src` 的 TSX/CSS 中不保留业务组件级十六进制色值。
- 移除的主题实现包括 `theme-provider`、布局中的主题启动脚本，以及账户菜单中的主题选项；账户菜单保留个人资料和退出相关交互。
- `DotMatrix` 使用 `--ornament`，`AccentSquare` 使用 `--accent`；它们仅是装饰，不表达业务状态。
