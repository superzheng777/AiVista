# AiVista 灵感社区浏览模块

> 对应迭代：前端迭代 6——公开灵感流与作品详情
> 当前状态：已完成
> 维护规则：本文件只定义公开页面行为、前端数据消费和验收条件；业务事实与接口安全边界以后端同名模块文档为准。

## 1. 页面范围

- `/` 是匿名可访问的灵感首页，展示按公开时间倒序的作品流。
- `/inspirations/[imageId]` 是匿名可访问的公开作品详情页，提供页面标题、描述和公开内容的 SEO 元数据。
- 首页和详情只展示图片、发布标题/描述、最终正负提示词、生成配置与公开时间。
- 展示作者头像、昵称、点赞数和已登录查看者的点赞/关注状态；头像和昵称链接到迭代 5 的作者主页。
- 不展示评论、搜索、热门或推荐入口；这些能力尚无数据与交互契约，不做视觉占位。

## 2. 数据与缓存规则

| 目的 | 接口 | 前端行为 |
| --- | --- | --- |
| 首屏及继续加载 | `GET /api/inspirations?cursor` | 使用服务端 `nextCursor` 加载下一页，禁止由前端推算页码或游标；批量规则见《发现能力模块》。 |
| 作品详情 | `GET /api/inspirations/{imageId}` | 路由参数只使用字符串 ID；404 显示公开作品不存在或已撤销，不区分原因。 |

- 公开内容、排序和 SEO 不依赖登录态；客户端仅为当前查看者读取单张作品的点赞状态及作者关注状态。不在 `localStorage`、URL、埋点或错误监控中写入签名 URL、提示词或作品正文。
- 作品详情使用按请求动态渲染以满足 SEO；图片 URL 只有 10 分钟有效期，不能静态生成或跨请求持久缓存。SEO 元数据只使用标题和描述，不包含签名 URL、提示词或私有信息。
- 路由首次按请求读取公开作品，详情覆盖层再只请求该单张作品以校验当前公开状态、签名 URL 和当前查看者的点赞状态；不会重拉灵感分页列表。
- 详情与列表复用迭代 4 的完整图片 DTO，并消费迭代 5 提供的作者公开资料、点赞数与互动状态；匿名返回的 `favorited`、`likedByCurrentUser` 固定为 `false`，前端不显示收藏控件。作者资料及关注状态通过 `GET /api/users/{authorId}` 按需读取，不嵌入图片 DTO。
- 灵感页不订阅 SSE；用户刷新或重新进入页面时从第一页读取新快照。

## 3. 交互与视觉约束

- 首页沿用 [UI设计.md](UI设计.md) 的暖白背景、固定侧栏和灵感网格视觉方向；本迭代以真实公开数据替换静态灵感占位。
- 仅作品网格工具栏可以 `sticky`；工具栏与网格严格共用左右内容边距，吸顶时使用连续的扁平顶栏，不将整个内容卡片吸顶。
- 首版工具栏只承担布局和“发现”当前态，不展示没有后端语义的“热门”“新作”切换或搜索输入。
- 点击作品进入公开详情路由。站内导航时详情以当前来源页面为背景覆盖显示，关闭后回到该来源；直接访问或刷新 URL 时以灵感首页为背景，关闭后进入灵感首页。资产详情保持页内打开且不改变 URL。链接、按钮、图片替代文本、加载、空态和错误态必须可键盘访问。
- 向下滚动加载更多时保留已展示项目；失败时不清空现有内容，并提供重试。

## 4. 非功能约束

- 未登录可浏览；登录与否不改变公开内容、排序或详情字段。
- 公开作品详情展示 `publicAt` 作为发布时间；私有资产详情继续展示 `createdAt` 作为生成时间。
- 作品撤销后详情显示 404 页；列表的旧项在下一次请求时由服务端快照移除。
- 不使用客户端伪造分页、点赞数、作者信息或收藏状态。
- 页面不依赖发布区、资产页或消息抽屉的缓存，公开页面的数据以灵感接口响应为准。

## 5. 验收条件

1. 匿名访问首页和详情不触发登录或用户协议确认。
2. 首页按服务端游标连续滚动且无重复；没有下一页时不再发起加载。
3. 详情仅展示已公开作品；撤销后访问返回统一不存在状态。
4. 窄屏和键盘操作下，网格、加载更多、详情返回、加载/空/错误态均可用。
5. 页面及 SEO 元数据不泄露签名 URL、审核数据、内部提示词上下文或会话历史。

## 6. 后续边界

点赞、计数、作者公开资料与关注属于迭代 5；列表分页扩展与关注列表由《发现能力模块》承接。未交付能力不以静态 UI 冒充可用功能。
