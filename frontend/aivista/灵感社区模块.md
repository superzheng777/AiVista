# AiVista 灵感社区浏览模块

> 对应迭代：前端迭代 6——公开灵感流与作品详情（后续交互调整已同步）
> 当前状态：已完成
> 维护规则：本文件只定义公开页面行为、前端数据消费和验收条件；业务事实与接口安全边界以后端同名模块文档为准。

## 1. 页面范围

- `/inspirations` 是匿名可访问的灵感页面，默认展示按公开时间倒序的发现列表；`/` 重定向至该页面。
- `/inspirations?imageId={imageId}` 是匿名可访问的公开作品详情地址；直接访问、新标签或刷新时在客户端读取单图快照。
- 首页和详情只展示图片、发布标题/描述、最终正负提示词、生成配置与公开时间。详情中正向与负向提示词分块标注并原文展示，前端不做翻译或拼接；负向值为空时不显示该区块。
- 公开详情作者区收敛为一行：左侧展示作者头像、昵称以及仅对非本人显示的关注按钮，右侧展示点赞图标、点赞数和“更多”菜单；不再展示“关注者数 / 获赞数”，也不再保留独立的“作者”和“公开互动”区块。头像和昵称链接到迭代 5 的作者主页。当前灵感瀑布流卡片只使用列表 DTO 已有的标题、点赞数与当前查看者点赞状态，不逐卡请求作者资料；卡片底部点赞按钮直接复用列表快照完成乐观更新。
- 不展示评论、热门或推荐入口；发现/关注导航及关键词搜索已由后续迭代接入，不额外伪造分类、排序或筛选控件。

## 2. 数据与缓存规则

| 目的 | 接口 | 前端行为 |
| --- | --- | --- |
| 首屏及继续加载 | `GET /api/inspirations?cursor` | 使用服务端 `nextCursor` 加载下一页，禁止由前端推算页码或游标；批量规则见《发现能力模块》。 |
| 作品详情 | `GET /api/inspirations/{imageId}` | 路由参数只使用字符串 ID；404 显示公开作品不存在或已撤销，不区分原因。 |

- 公开内容和排序不依赖登录态；客户端仅为当前查看者读取单张作品的点赞状态及作者关注状态。不在 `localStorage`、URL、埋点或错误监控中写入签名 URL、提示词或作品正文。
- 当前公开详情明确不做 SSR，也不生成按作品变化的标题、描述或 SEO 元数据。`thumbnail/display` URL 有效期为 1 天，但仍不能跨请求持久缓存。当前已完成静态导出兼容的查询参数路由改造；本地仍运行 Next 开发服务器，通过 rewrite 与 SSE Route Handler 联调。未来切换 Nginx 静态托管时再开启 `output: "export"`、由 Nginx 代理同源 `/api` 和 SSE，并删除 Next 代理代码。
- 直接访问详情路由时由浏览器请求单图公开快照；从已加载列表、搜索、作者主页、发布区或已审核通过消息打开时可立即复用其 `thumbnail` 与 `display`，不重拉来源列表或单图详情。
- 详情与列表复用统一图片 DTO：列表仅使用 `imageUrls.thumbnail`，公开详情展示及非作者下载使用 `display`。公开详情的“更多”菜单对所有查看者提供下载：匿名或非作者下载公开 `display.webp`，登录作者通过专属下载接口取得原图。匿名返回的 `favorited`、`likedByCurrentUser` 固定为 `false`，前端不显示收藏控件。作者资料及关注状态通过 `GET /api/users/{authorId}` 按需读取，不嵌入图片 DTO。
- 发现页不订阅 SSE；用户刷新或重新进入页面时从第一页读取新快照。

## 3. 交互与视觉约束

- 首页沿用《UI 设计/灵感页面设计》的暖色编辑排版、固定侧栏和灵感瀑布流视觉方向；本迭代以真实公开数据替换静态灵感占位。
- 仅作品网格工具栏可以 `sticky`；工具栏与网格严格共用左右内容边距，吸顶时使用连续的扁平顶栏，不将整个内容卡片吸顶。
- 当前工具栏展示“发现 / 关注”两个列表标签；关键词搜索入口与结果页由《关键词搜索模块》维护。
- 普通左键点击公开作品时以当前来源页面为背景打开覆盖层，并用 History API 在当前灵感列表查询参数上追加 `imageId`；覆盖层与资产详情使用相同的全高双栏布局，桌面端保留 88px 全局导航并铺满其余内容区，不再套用居中限宽卡片、四周留白或黑色遮罩。详情使用纯图标上下箭头按来源数组顺序切换，切换时以 `replaceState` 更新当前 `imageId`，到达已加载末尾且存在下一页时先加载下一页再继续。图片周边留白、图片区域左上角返回键和浏览器后退使用同一关闭语义：从列表进入时返回原来源并保留列表、分页和滚动位置；直接访问或刷新 `/inspirations?imageId={imageId}` 时不预加载灵感列表、不显示无来源的上下导航，关闭后替换到 `/inspirations`。Ctrl/⌘ 点击、中键、新标签和复制链接保留正常链接行为。资产详情保持页内打开且不改变 URL。链接、按钮、图片替代文本、加载、空态和错误态必须可键盘访问。
- 公开详情复用资产详情的全高双栏 Shell，但使用独立的公开作品工具栏：作者信息单行排列，右侧依次为点赞图标、点赞数和“更多”；“更多”菜单始终包含下载，仅作者额外显示“撤销发布”。共享 Shell 顶部不再重复显示下载按钮，作品信息区也不重复发布时间。
- 作者工具栏下一行只显示 `YYYY-MM-DD` 格式的公开日期和“内容由 AI 生成”。详情上下切换沿用近黑浮层；返回、点赞和更多菜单使用暖色悬停与陶土焦点，点赞选中态使用陶土强调，撤销发布使用语义危险色，避免出现与全局主题无关的蓝色或粉色交互态。
- 灵感卡片底部心形为真实点赞按钮：未登录点击打开登录弹窗；已登录时立即更新心形与计数并提交现有点赞接口，请求失败恢复原快照，请求进行中禁止重复提交。点击点赞不得同时打开作品详情。
- 向下滚动加载更多时保留已展示项目；失败时不清空现有内容，并提供重试。

## 4. 非功能约束

- 未登录可浏览；登录与否不改变公开内容、排序或详情字段。
- 公开作品详情展示 `publicAt` 作为发布时间；私有资产详情继续展示 `createdAt` 作为生成时间。
- 单图请求时作品已撤销则显示统一不可访问状态；已从列表打开的详情是内存快照，不轮询撤销或点赞变化。对该快照发起点赞等状态变更时仍由服务端裁决，失败后前端回滚；列表旧项在下一次请求时由服务端快照移除。
- 不使用客户端伪造分页、点赞数、作者信息或收藏状态。
- 页面不依赖发布区、资产页或消息抽屉的缓存，公开页面的数据以灵感接口响应为准。

## 5. 验收条件

1. 匿名访问首页和详情不触发登录或用户协议确认。
2. 首页按服务端游标连续滚动且无重复；没有下一页时不再发起加载。
3. 详情仅展示已公开作品；撤销后访问返回统一不存在状态。
4. 窄屏和键盘操作下，网格、加载更多、详情返回、加载/空/错误态均可用。
5. 页面不在持久化存储、URL、埋点或错误监控中泄露签名 URL、审核数据或会话历史；当前不提供单作品 SSR SEO 元数据。
6. 从发现或关注列表打开详情时保留上下切图与来源查询参数；图片区域左上角返回和图片周边留白均回到来源列表，直接 URL 详情则回到灵感首页。
7. 卡片点赞在登录后可切换状态和数量，失败时回滚；匿名点击只触发登录，不修改计数。
8. 公开详情作者信息保持单行，不展示关注者数、作者获赞数或独立互动区；非本人显示关注按钮，本人不显示。
9. 公开详情的更多菜单对所有查看者提供下载，作者另有撤销发布；匿名或非作者下载公开展示图，作者下载原图。
10. 公开日期和“内容由 AI 生成”只在作者工具栏下一行展示；共享顶部不重复下载，作品信息区不重复发布时间。

## 6. 后续边界

点赞、计数、作者公开资料与关注属于迭代 5；发现列表分页与关注列表由《发现能力模块》承接，关键词搜索由《关键词搜索模块》承接。未交付能力不以静态 UI 冒充可用功能。
