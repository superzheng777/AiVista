# AiVista 应用壳层与用户认证模块

> 对应迭代：前端迭代 1——应用壳层与用户认证
> 当前状态：已完成
> 维护规则：本文记录应用壳层、用户认证和个人资料的前端交互；代码、测试、接口契约或交互规则变化时必须同步修改。

## 1. 目标与范围

已建立灵感、生成、资产之间的统一导航，完成登录/注册、会话恢复、个人资料编辑和退出登录。生成、资产和灵感真实业务数据不属于本模块。

## 2. 已确认约束

- 桌面端使用固定侧栏，移动端使用底部导航。
- 登录和注册在当前页面的居中悬浮卡片中完成，不设独立登录路由。
- Access Token 仅保存在内存；会话恢复、刷新与认证失效规则遵循工程基础文档。
- 匿名直接访问 `/generate`、`/assets`、`/profile` 时返回首页，不自动打开登录卡片。

## 3. 关键决策记录

| 决策事项 | 最终结论 | 原因与取舍 | 对实现的影响 |
| --- | --- | --- | --- |
| 认证入口 | 当前页悬浮登录/注册卡片。 | 保持浏览上下文，无需登录路由。 | 受保护操作通过认证对话框接口触发。 |
| 会话恢复 | 先请求当前用户资料，由拦截器单飞刷新。 | 统一处理初次加载和运行中的 Token 过期。 | Provider 不直接调用刷新接口。 |
| 主题偏好 | 仅保存于浏览器本地。 | 不引入用户服务端配置。 | 首次绘制前恢复主题，避免闪烁。 |

## 5. 页面、路由与交互设计

| 路由 | 页面 | 当前行为 |
| --- | --- | --- |
| `/` | 灵感首页 | 静态创作入口与灵感布局骨架。 |
| `/generate` | 生成工作台入口 | 已登录可进入，真实生成能力由迭代 2 接入。 |
| `/assets` | 个人资产入口 | 已登录可进入，真实资产由迭代 3 接入。 |
| `/profile` | 个人主页 | 查询和编辑当前用户资料，并可退出登录。 |

桌面端头像悬停展示账户菜单，移动端头像直接进入个人主页。主题提供浅色、深色和跟随系统；退出操作要求二次确认。

## 6. API、前端模型与状态管理

| 前端行为 | 后端接口 |
| --- | --- |
| 注册/登录 | `POST /api/auth/register`、`POST /api/auth/login` |
| 会话恢复/当前用户 | `GET /api/users/me` |
| 刷新/退出 | `POST /api/auth/refresh`、`POST /api/auth/logout` |
| 修改资料 | `PUT /api/users/me` |

认证状态为 `loading`、`authenticated`、`anonymous`、`error`。仅刷新接口返回 `40102` 或用户主动退出才进入 `anonymous`；网络异常进入 `error` 并保留状态。

## 8. 异常场景、可靠性与安全

`40100` 由全局拦截器刷新并重放；`40102` 清理会话。网络/服务异常不判定退出。公开页的后续受保护单次操作保持当前页面，并由操作自身打开登录卡片。
