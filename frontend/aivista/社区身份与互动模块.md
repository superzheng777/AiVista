# AiVista 社区身份与互动基础模块

> 对应迭代：前端迭代 5——作者主页、关注与点赞
> 当前状态：设计准入中，尚未实现
> 维护规则：本文件定义作者主页与互动的用户可见行为；公开字段、权限与接口以后端同名模块文档为准。

## 1. 页面与交互范围

- `/users/[userId]` 是自己与他人共用的作者主页路由，使用稳定的原始字符串用户 ID；资料区展示头像、昵称、简介、粉丝数、关注数与获赞数。点赞列表是否公开只作为本人可编辑的隐私设置，不向他人额外展示状态文字。
- 自己访问主页时显示资料编辑和“公开点赞列表”设置，默认关闭，不显示关注按钮；访问他人主页时显示关注/已关注按钮。
- 主页的“作品”分区自己与他人均只展示已公开、审核通过的作品；当前用户额外拥有仅自己可见的“审核中”分区，使用发布审核详情，他人永远看不到。
- 作者允许公开点赞列表时展示“点赞”分区，否则不显示该分区；他人的公开分区只包含当前仍公开的作品。本人查看自己的点赞列表时，除有效作品外还显示“作品已下架”占位。
- 现有“我的发布”列表的作品卡片与详情加入点赞按钮和点赞数；仅审核通过且当前公开的作品显示点赞交互，审核中作品只展示审核状态。
- 作者主页的作品分区沿用现有整列表加载方式；不为作者主页单独新增分页或“加载更多”，全站灵感流的分页在迭代 6 统一实现。
- 已审核通过的“我的发布”详情与灵感详情复用同一图片详情基础组件和公共交互；通过 `isOwner` 附加撤销发布等作者管理区。审核中作品只在作者发布列表中展示审核状态和取消审核，不进入公共详情，也不显示点赞。
- 作品列表卡片仅展示图片；不在卡片上展示作者头像、昵称或其他作者资料。点击卡片打开详情，只有已公开作品详情才展示作者头像、昵称等资料，并加载一次作者公开资料；作者头像、昵称可跳转至 `/users/[userId]`。资产详情不展示作者入口或请求作者资料。
- 不在本迭代实现全站灵感流、公开作品详情、搜索、热门或推荐页面。

## 2. 统一展示规则

- 已公开作品详情中的作者头像、昵称链接到 `/users/[userId]`。
- 自己与他人资料区复用同一公开作者组件；编辑、隐私设置和关注按钮作为页面权限层附加，不复制资料布局。
- 自己的主页同样访问 `/users/[currentUserId]`；现有独立个人主页路由如需保留，只重定向至该地址，不维护第二套页面。
- 图片列表直接消费统一图片 DTO 的 `likeCount`、`likedByCurrentUser` 与轻量作者摘要，不为单张图片的点赞状态发起额外请求。
- 已公开作品详情在取得图片的 `authorId` 后，额外请求一次作者公开资料，用于展示简介、粉丝数、关注数、获赞数和当前用户的关注状态；不区分入口来自灵感列表、自己的已发布列表、他人主页作品或公开点赞列表。详情没有独立 URL，不能直接访问或刷新恢复；打开详情时直接使用列表中的完整图片 DTO。审核中和资产详情不请求作者资料。
- 页面首次加载时以图片 DTO 的 `likedByCurrentUser`、`likeCount` 和作者资料的 `viewerFollowing`、`followerCount`、`likesPublic` 初始化视图。
- 关注、点赞和点赞列表公开设置均采用明确目标状态的幂等接口：`PUT` 确保关系或设置存在，`DELETE` 确保关系不存在；成功统一返回 `204 No Content`。当前控件请求期间禁用，成功后前端按本次目标状态更新视图和本地计数，失败则保持原状态并提示。
- 成功操作后使相关图片列表、详情和作者资料缓存失效并后台重拉；重拉结果为计数与状态的最终校正，覆盖其他用户并发操作带来的差异。点赞按钮依据 `likedByCurrentUser` 展示不同图标与操作意图，未登录点击时引导登录。
- 未登录用户可看资料与已发布作品；点击关注或点赞时引导登录，不伪造成功状态。
- 用户撤销发布后，作品的点赞数在服务端归零；重新发布后前端以新的服务端快照展示，不保留旧点赞数。
- 用户撤销发布后，作品立即从灵感、作者“作品”分区和他人的公开点赞列表移除，并回到资产库；再次公开需重新提交审核。点赞过该作品的用户本人保留“作品已下架”占位，可手动取消该历史点赞；重新发布不会自动恢复旧点赞。

## 3. 隐私与空态

- “点赞列表”默认仅自己可见；作者主动公开后才对他人显示入口。切换回私密后立即隐藏入口；直接访问未公开列表时显示统一不存在状态，已加载的旧数据在下一次刷新或后台重拉后移除。
- 本人始终能查看自己的点赞列表和当前隐私状态。
- “作品已下架”占位不展示原图、标题、作者或生成参数，不可打开详情；仅本人可见，并提供移除该条历史点赞的操作。
- 用户没有已发布作品、没有点赞作品或主页请求失败时，保留资料区并显示对应空态或重试。

## 4. 验收条件

1. 已公开作品详情中的作者头像、昵称可进入对应作者主页；列表卡片与资产详情不展示作者入口。
2. 用户资料字段在自己与他人主页一致，均展示粉丝数、关注数和获赞数，只有权限操作不同；自己的主页也通过 `/users/[userId]` 加载。
3. 图片列表不为 `likedByCurrentUser` 触发逐图请求；灵感详情仅额外加载一次作者公开资料。关系操作成功以 `204` 为准，前端按目标状态更新后后台重拉，以服务端 DTO 校正状态与计数。
4. 未登录访问公开主页不触发用户协议确认，敏感账户字段不显示。
