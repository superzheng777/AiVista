# AiVista 灵感社区浏览模块

> 对应迭代：迭代 6——公开灵感流与作品详情
> 当前状态：已完成
> 维护规则：本文记录公开作品读取的边界、接口和图片 URL 规则；代码、测试和文档必须同步修改。

## 1. 范围与边界

匿名或已登录用户可浏览当前已发布作品。唯一筛选条件为 `public_at IS NOT NULL` 且 `publication_review_status = 'APPROVED'`；资产是否软删除不影响已公开作品的可见性。撤销、审核中、拒绝、失败或不存在的作品不能通过公开接口读取，并统一按资源不可用处理。

公开响应使用与资产、我的发布和通知一致的图片 DTO：`imageUrls` 固定包含 `thumbnail`、`display` 两个可空字段，每个非空字段为 URL 与到期时间；原图不出现在普通 DTO。列表渲染 `thumbnail`，详情复用 `display`；原图仅可由认证作者调用专属下载接口按需取得。其余字段包含公开标题和描述、最终提示词及生成配置、`authorId`、`likeCount`、`likedByCurrentUser`、`publicationVersion`。`favorited` 对公开读取固定为 `false`，不暴露作者私有收藏状态；作者资料和关注状态由迭代 5 的用户接口按需读取，不嵌入图片 DTO。

不返回会话历史、系统提示词、内部上下文、服务商参数、对象键、审核记录或异常详情。

## 2. 当前 API 契约

| 功能 | 方法与路径 | 当前行为 |
| --- | --- | --- |
| 发现列表 | `GET /api/inspirations?cursor` | 匿名可读，按 `public_at DESC, id DESC` 返回已发布作品；响应为 `{ items, nextCursor }`，分页批量与游标规则见《发现能力模块》。 |
| 公开作品单图详情 | `GET /api/inspirations/{imageId}` | 匿名可读，仅返回当前仍已发布的单张完整图片 DTO，并签发新的短期 URL；下架或不存在统一不可读。 |

## 3. 签名 URL、缓存与详情打开

- 私有对象组始终保留在私有 OSS Bucket；每组由 `original.png`、`card.webp`、`display.webp` 构成。公开读取也只返回短期签名 URL，不创建公开 Bucket 或公开副本。
- 当前签名有效期为 10 分钟。API JSON 响应不缓存；新上传对象设置浏览器私有缓存，缓存上限与签名期一致。
- 列表图片使用 `thumbnail`、原生懒加载和异步解码。打开详情优先复用现有 DTO 的 `display`，URL 到期或实际读取失败时最多刷新该单张图片一次，不自动刷新整个列表。复制使用 `display`；下载原图时仅认证作者调用专属下载接口申请临时 URL。
- 公开详情路由和站内详情覆盖层通过单图接口校验当前公开状态并在需要时签发当前图片 URL；客户端不得因一张图片刷新整个公开列表。

## 4. 后续边界

列表分页扩展与关注列表由《发现能力模块》承接。灵感流不订阅 SSE；用户重新进入或刷新页面时重新读取当前公开数据。
