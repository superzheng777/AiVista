# AiVista 灵感社区浏览模块

> 对应迭代：迭代 6——公开灵感流与作品详情
> 当前状态：实施中（首版公开列表和单图详情已实现；游标分页、搜索、热门排序与推荐未实现）
> 维护规则：本文记录公开作品读取的边界、接口和图片 URL 规则；代码、测试和文档必须同步修改。

## 1. 范围与边界

匿名或已登录用户可浏览当前已发布作品。唯一筛选条件为 `public_at IS NOT NULL` 且 `publication_review_status = 'APPROVED'`；资产是否软删除不影响已公开作品的可见性。撤销、审核中、拒绝、失败或不存在的作品不能通过公开接口读取，并统一按资源不可用处理。

公开响应使用与资产、我的发布和通知一致的完整图片 DTO：包含图片 URL 与到期时间、公开标题和描述、最终提示词及生成配置、`authorId`、`likeCount`、`likedByCurrentUser`、`publicationVersion`。`favorited` 对公开读取固定为 `false`，不暴露作者私有收藏状态；作者资料和关注状态由迭代 5 的用户接口按需读取，不嵌入图片 DTO。

不返回会话历史、系统提示词、内部上下文、服务商参数、对象键、审核记录或异常详情。

## 2. 当前 API 契约

| 功能 | 方法与路径 | 当前行为 |
| --- | --- | --- |
| 灵感列表 | `GET /api/inspirations` | 匿名可读，按 `public_at DESC, id DESC` 返回最新最多 36 张已发布作品的数组；当前不接收 `cursor` 或 `limit`，不返回 `nextCursor`。 |
| 公开作品单图详情 | `GET /api/inspirations/{imageId}` | 匿名可读，仅返回当前仍已发布的单张完整图片 DTO，并签发新的短期 URL；下架或不存在统一不可读。 |

## 3. 签名 URL、缓存与详情打开

- 私有原图始终保留在私有 OSS Bucket；公开读取也只返回短期签名 URL，不创建公开 Bucket 或公开副本。
- 当前签名有效期为 10 分钟。API JSON 响应不缓存；新上传对象设置浏览器私有缓存，缓存上限为签名期减 30 秒。
- 列表图片使用原生懒加载和异步解码。图片加载失败仅显示不可用状态，不自动刷新列表或重复请求 OSS。
- 用户打开详情时，URL 仍有效则直接复用列表 DTO；URL 已到期、无法解析或距当前不足 30 秒时，只调用单图详情接口刷新该图片。不得因一张图片过期刷新整个公开列表。

## 4. 后续边界

公开灵感流的游标分页、关键词搜索、热门排序和推荐尚未实现。引入分页时必须替换当前固定上限列表语义，不并存两套等价列表接口；分页响应、游标编码、排序边界和验收条件须在实施前补充到本文。
