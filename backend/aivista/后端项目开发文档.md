## 2. 一期目标

一期后端支持普通用户生成并管理 AI 图片，将作品发布到社区，并完成公开浏览、点赞和关注闭环。

## 3. 跨模块已确认业务边界

| 主题 | 已确认规则 |
| --- | --- |
| 用户 | 一期仅支持普通用户。 |
| 生成 | 当前使用 `qwen-image-2.0`，单次生成 1 至 6 张图片。 |
| 资产 | 成功生成的图片进入个人历史；收藏不决定资产是否保留。 |
| 发布 | 审核通过后作品公开；原图保存在私有 OSS，公开读取使用短期签名 URL。资产删除与撤销发布相互独立。 |
| 公开内容 | 可公开最终提示词和生成配置，不公开会话历史、内部上下文、服务商参数或系统提示词。 |
| 互动 | 一期支持图片点赞以及用户关注。 |

## 5. 文档同步规则

- 新迭代编码前建立对应模块文档并完成设计准入。
- 业务规则、数据、API、可靠性或测试变化更新模块文档。
- 迭代状态、跨模块边界或文档索引变化更新本文档。
- 工程运行、通用配置或部署约定变化更新工程基础文档。
- 不受影响的文档不机械修改；敏感信息不得写入文档。
