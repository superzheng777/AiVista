# AiVista 收藏与发布模块

> 对应迭代：迭代 4——收藏与发布
> 当前状态：设计中
> 维护规则：本文记录迭代 4 的范围、约束、设计结论和实施进度；代码、测试、接口或数据结构变更时必须同步修改。

## 1. 目标与范围

本迭代拟在已有个人生成资产的基础上，支持当前用户：

- 收藏或取消收藏自己的生成图片；
- 按收藏状态筛选个人资产；
- 将自己的生成图片发布为公开内容；
- 撤销已发布内容。

发布完成后提供稳定的公开图片直达链接。公开内容浏览、详情、点赞、关注、推荐、付费和局部重绘均不在本迭代实现范围。

## 2. 待核对约束

以下内容均为待讨论项，不构成实施约束：

- 收藏与发布是否均以单张生成图片为最小对象；
- 是否只允许图片所有者收藏、发布和撤销发布；
- 私有原图与公开副本的关系、公开 URL 的形式和可访问时机；
- 撤销发布是否影响私有原图、资产、任务、会话或提示词历史；
- 发布时提示词的公开范围、确认方式和是否保留快照；
- 已发布图片与个人资产删除操作之间的关系；
- 发布过程是否异步，以及失败、重试、并发和幂等策略。

## 3. 待核对决策清单

| 决策事项 | 当前状态 | 需要确认的重点 |
| --- | --- | --- |
| 迭代范围与公开可访问性 | 已确认 | 发布完成后提供稳定公开图片直达链接；不提供社区列表、公开详情页或提示词浏览。 |
| 收藏对象与存储模型 | 已确认 | 收藏是所有者对自己私有生成资产的个人标记；本迭代直接存为资产字段，不涉及他人公开作品。未来若支持收藏他人作品，新增“用户 × 图片/发布内容”唯一关系表，并迁移当前收藏标记。 |
| 收藏筛选与分页 | 已确认 | 扩展既有个人资产列表，以“全部/已收藏”筛选并沿用当前排序和不透明游标；切换筛选从第一页开始。 |
| 发布资源模型 | 已确认 | 每次发布创建独立发布记录和新的稳定公开标识；同图可多次发布。撤销后旧链接永久失效，再发布不得复用。 |
| 公开副本和存储 | 待核对 | 是否复制、复制何种尺寸、同步或异步、公开 URL 的归属。 |
| 提示词公开 | 待核对 | 公开哪些消息、何时确认、是否留存快照、后续是否可修改。 |
| 撤销发布 | 待核对 | 立即不可见、物理清理时机、是否支持重新发布。 |
| 删除边界 | 待核对 | 删除时阻止、自动撤销、级联处理或其他规则。 |
| API、权限与可靠性 | 待核对 | 写接口形态、幂等键、错误契约、竞争和失败恢复。 |
| 前端交互 | 待核对 | 入口位置、确认提示、处理中展示、刷新和缓存策略。 |
