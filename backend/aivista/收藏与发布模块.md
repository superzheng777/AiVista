# AiVista 收藏、发布审核与官方消息模块

> 对应迭代：后端迭代 4——收藏、异步文本审核发布与官方消息
> 当前状态：设计中，待完成新方案评审后实施
> 维护规则：本文是本迭代的唯一设计依据；代码、测试、接口或数据结构变化时必须同步更新。

## 1. 目标与边界

本迭代实现收藏与收藏筛选、发布标题和描述的异步内容审核、我的已发布图片列表、撤销发布，以及审核拒绝的官方消息。

生成原图始终存放在现有私有 OSS Bucket。发布不复制原图、不创建公开 Bucket、不创建发布专属快照。审核通过后，图片仍使用原对象键；灵感页的匿名接口只为当前已发布图片签发 10 分钟有效的私有 URL。短期 URL 是 bearer URL：撤销发布后，服务端立即停止签发新 URL，但已签发 URL 在过期前仍可能访问。

迭代 4 不实现公开灵感列表或详情、他人主页、点赞、关注、推荐或人工审核。图片与提示词安全由生成链路负责：生成模型拒绝不合格输入或图片时任务失败，发布环节不重复审核图片或提示词；后续迭代也应优先在生成阶段扩展这些审核。文本审核仅覆盖本次发布的标题和描述。

## 2. 已确认规则

| 主题 | 规则 |
| --- | --- |
| 收藏 | 收藏是 `generation_images` 的所有者标记；支持单张和条件式批量变更。未来收藏他人公开作品时另建关系表。 |
| 发布条件 | 仅所有者可提交未删除图片；可提交的必要条件为 `public_at IS NULL AND publication_review_status = NONE`。审核中即使 `public_at` 为空也不可重复提交。 |
| 发布输入 | 客户端只提交图片 ID、标题和可选描述。标题去除首尾空白后为 1–100 字符；描述最多 500 字符。不得提交或改写提示词、模型参数和对象键。 |
| 图片审核边界 | 发布不审核图片内容；图片安全依赖生成链路的模型审核与失败处理，不在发布流程增加重复调用。 |
| 提示词公开边界 | 后续灵感详情公开来自成功生成任务的最终提示词；生成失败或被生成链路拒绝的任务没有可发布图片。发布不重复审核提示词，不公开会话历史、系统提示词、服务商参数或内部工作流配置。 |
| 审核通过 | 审核通过才写入 `public_at`，图片从此作为已发布图片参与后续灵感页查询。 |
| 审核拒绝 | 不写入 `public_at`，状态回到 `NONE`，保留标题和描述以允许用户修改后重新提交；创建持久化官方消息，使用后端映射的安全文案。 |
| 已发布文案 | 已发布图片的标题和描述不可直接编辑，也不提供编辑接口；需要修改时必须先撤销发布，再以新文案重新提交审核。 |
| 撤销发布 | 撤销只清空 `public_at` 并清除当前发布文案，不删除私有资产或 OSS 对象；未删除资产可以重新提交审核。 |
| 删除资产 | 删除资产只写 `generation_images.deleted_at`，不清空 `public_at`，不取消正在进行的审核。已发布图片继续可供后续灵感页展示。 |
| 对象清理 | 仅当图片同时满足 `deleted_at IS NOT NULL AND public_at IS NULL`，且不存在审核中工作时，才异步删除私有 OSS 对象；删除必须可重试。 |
| 可见性 | 资产查询只按 `deleted_at IS NULL`；未来匿名灵感查询只按 `public_at IS NOT NULL`。两个视图互不从属。 |
| 幂等 | 提交审核是创建型命令，使用项目级 `idempotency_records`；收藏、撤销、删除和消息读写是状态型操作，不使用该表。 |

## 3. 审核状态机与可靠事件

```text
NONE -> QUEUED -> REVIEWING -> PUBLISHED
  ^       |            |
  |       +------------+-> NONE（审核拒绝、可重试系统失败或撤销）
  +----------------------- 撤销已发布后可重新提交
```

- `PUBLISHED` 的事实由 `public_at IS NOT NULL` 表示；`publication_review_status` 用于阻止审核中的重复提交并表达工作状态。
- `POST` 提交审核在同一事务内写入候选标题、候选描述、递增后的 `publication_version`、`QUEUED` 状态、幂等记录与 `PUBLICATION_TEXT_REVIEW` Outbox 事件，返回 `202 Accepted`。
- 工作器领取 `QUEUED` 后条件更新为 `REVIEWING`，分别同步调用阿里云内容安全增强版 PLUS 的 `TextModeration` 审核标题和描述。调用不在数据库事务内执行；发布流程之所以异步，是为隔离第三方审核延迟和失败，而不是因为审核 API 本身要求异步回调。
- 审核通过时，工作器仅在 `id + publication_version + REVIEWING` 匹配时写入 `public_at` 和 `PUBLISHED`。审核拒绝或可恢复系统失败时，只有相同条件匹配才回到 `NONE`；拒绝创建官方消息。迟到结果影响行数为 `0` 时直接丢弃。
- 撤销审核中或已发布图片时，递增 `publication_version` 并设为 `NONE`；这样任何迟到审核结果均不能重新公开图片。
- 工作器领取审核时递增 `publication_review_attempt_count` 并写入 `publication_review_started_at`。定时恢复器扫描超过审核超时仍为 `REVIEWING` 的图片，按相同版本重新置为 `QUEUED` 并写入新的 Outbox 事件；它防止工作器在领取后崩溃导致图片永久审核中。
- 审核服务的明确拒绝（包括“疑似”结果）不重试；可恢复网络或服务错误、超时和崩溃恢复共最多尝试 3 次，耗尽后回到 `NONE`，保留标题和描述，并创建“审核暂不可用，请稍后重试”的官方消息。用户只能手动重新提交，不会被自动公开。所有用户可见原因均由后端映射，禁止透传供应商原始响应、对象键、异常堆栈或密钥。
- 用户通过资产/我的发布 REST 快照对账审核状态；审核结果和官方消息的未读数可复用既有用户 SSE，但 REST 是权威来源。

## 4. 数据模型与迁移

`generation_images` 是私有资产和已发布图片的唯一事实表。建议新增：

| 字段 | 约束与用途 |
| --- | --- |
| `favorited` | `BOOLEAN NOT NULL DEFAULT FALSE`，仅所有者可见；建立 `(user_id, favorited, deleted_at, created_at DESC, id DESC)` 索引。 |
| `public_at` | `DATETIME(3) NULL`；非空代表当前已发布。未来灵感页按它及稳定游标排序。 |
| `publication_review_status` | `VARCHAR(16) NOT NULL DEFAULT 'NONE'`，取值 `NONE`、`QUEUED`、`REVIEWING`、`PUBLISHED`。 |
| `publication_version` | `BIGINT UNSIGNED NOT NULL DEFAULT 0`；提交、撤销和工作器状态转换均递增或匹配它，隔离迟到审核结果。 |
| `publication_review_attempt_count` / `publication_review_started_at` | 审核执行次数与本次领取时间；用于最多 3 次重试及超时工作恢复。建立 `(publication_review_status, publication_review_started_at)` 索引。 |
| `publication_title` | `VARCHAR(100) NULL`；审核中的候选标题与当前已发布标题均保存于此。 |
| `publication_description` | `VARCHAR(500) NULL`；审核中的候选描述与当前已发布描述均保存于此。 |

已发布列表可从 `generation_images` 联合 `generation_tasks` 与 `users` 查询；图片 ID 即公开作品 ID，不另建 `image_publications` 表。标题和描述在 `public_at` 为空时不进入公共查询。未来如需要保留多次发布历史、独立快照或审核审计，再单独设计表，不在一期预埋。

保留通用 `outbox_events` 和 `idempotency_records`。`user_notifications` 用于官方消息，本迭代至少支持 `PUBLICATION_TEXT_REJECTED` 与 `PUBLICATION_REVIEW_UNAVAILABLE` 两类事件；消息不暴露审核供应商原始分类。

审核适配层固定使用阿里云内容安全增强版 PLUS 的 `TextModeration`，以 RAM 最小权限凭证调用，凭证仅由部署环境注入。标题与描述分别提交，供应商的原始响应、风险标签和用户原文不写入普通日志或官方消息；仅保存实现重试与排障所需的安全错误分类。提交发布前，用户必须已在注册、登录或会话恢复时同意当前版本的 `USER_AGREEMENT`；协议明确告知标题与描述会发送至阿里云内容安全服务审核，并通过现有 `user_consents` 持久化版本与确认时间。未同意或版本过期时拒绝受理发布。

开发数据库会清空并重新迁移，因此直接重写 V7：删除旧“公开副本与发布记录”方案的 `image_publications` 等结构，保留通用 Outbox 与防重表，并新增本方案所需的 `generation_images` 审核、发布和收藏字段及索引。不新增 V8，也不保留旧结构兼容层。

## 5. API 与权限

| 功能 | 方法与路径 | 关键约束 |
| --- | --- | --- |
| 收藏/取消收藏 | `POST /api/generation-images/favorite`、`POST /api/generation-images/unfavorite` | 请求 `{"imageIds":["101"]}`；仅改变当前用户未删除资产，对无权或不存在 ID 幂等空成功。 |
| 资产筛选 | `GET /api/generation-images?filter=all|favorited` | 仅返回当前用户且 `deleted_at IS NULL` 的图片。 |
| 提交发布审核 | `POST /api/generation-images/{imageId}/publication-review` | 必带 UUID v4 `Idempotency-Key`；成功返回 `202` 与图片 ID、`QUEUED`、创建时间。 |
| 撤销发布/审核 | `DELETE /api/generation-images/{imageId}/publication` | 仅所有者；撤销 `QUEUED`、`REVIEWING` 或已发布状态，重复撤销幂等成功。 |
| 我的发布 | `GET /api/my-publications?cursor=&limit=` | 从图片表查询当前用户 `public_at IS NOT NULL` 的图片；审核中的项目不进入此列表，资产 DTO 可显示审核中状态。 |
| 官方消息 | `GET /api/official-messages` 等 | 仅当前用户；审核拒绝和审核服务不可用均由消息展示。 |

未来迭代 5 的匿名灵感接口只返回 `public_at IS NOT NULL` 且未被撤销的图片，并为图片原对象键签发 10 分钟 URL。公开详情从来源成功任务读取最终提示词，不返回会话历史、系统提示词、服务商参数或内部工作流配置。未登录访问不需要用户身份，但不得借此访问未发布资产；撤销后详情立即 `404`，旧签名 URL 仅能存活到其到期时间。客户端在 URL 到期前 30 秒刷新，图片加载失败时重新获取权威快照。匿名列表、详情和签名 URL 刷新接口必须实施 IP 级限流；网关/WAF 负责基础防爬和 DDoS 防护，应用不记录完整 IP 或签名 URL。

## 6. 验收与待确认项

- 同图并发提交只有一个请求能从 `NONE` 进入 `QUEUED`；同键重试返回首次受理快照，不同 key 返回“审核处理中”或“已发布”。
- 审核通过后匿名灵感查询可获得短期 URL；未通过、审核中、已撤销或从未发布的图片一律不可经匿名接口获取。
- 资产删除不影响已发布图片；撤销发布不影响未删除资产；两者均不可见后才清理 OSS 对象。
- 撤销审核中图片后，迟到的审核通过结果不得重新写入 `public_at`。
- 审核拒绝与服务不可用分别产生安全、可读的官方消息；消息读写、未读数和跨标签同步正确。
- 已确认使用阿里云内容安全增强版 PLUS `TextModeration`；实施前需在配置评审中确定具体地域、调用超时、限流退避和 RAM 最小权限策略，并完成第三方数据处理说明文案。
