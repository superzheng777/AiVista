# 生成工作台模块

> 当前状态：已完成。统一历史与实时模型及四区回复展示，详情和资产操作复用既有组件。

## 1. 目标与范围

生成页支持普通/Agent 创作、历史会话、需求表单、停止和结果浏览。用户可在当前会话输入新需求，并手动添加参考图发起下一次创作。路由 `/generate?sessionId={id}` 选择会话，新会话在首次提交时创建。

## 2. 已确认约束

会话摘要和单个会话都全量加载，不分页。每个会话最多 30 次用户创作，达到上限禁止新增，已有表单可继续。普通生成与 Agent 使用统一 POST /creations；AUTO 和数量 0 只属于编辑器状态，请求中转为省略配置。

## 3. 关键决策记录

QueryClient 的 SessionDetail 是页面唯一创作状态。历史接口初始化它，SSE 修改其中的轮次和内容项；不维护独立 Agent liveRuns，也不每帧刷新历史。组件统一渲染 turns/items，无论数据来自快照还是实时事件。

## 4. 实施计划与进度

API 和模型已切换；完成四区组件拆分、原生会话投影、历史/SSE 合并、提前事件缓冲、表单字段值提交和构造 30 轮边界。专用测试账号完成一次普通生成与一次带表单的 Agent 生成，各交付一张图片。

## 5. 页面、路由与交互设计

桌面侧栏列出全部会话；移动端隐藏侧栏并聚焦当前会话。用户输入气泡和助手区按创作顺序展示，图片 lazy loading，JSON 响应和对象仍全量进入内存。

会话内容区不设顶部标题栏；资产库入口独立固定在内容区右上角，不随历史消息滚动。左侧每个会话条目的“…”菜单提供“重命名”和“删除”。重命名原位编辑，使用 React Hook Form + Zod 统一管理表单与校验，回车或点击编辑框外自动保存，不设确认、取消按钮；Escape 放弃编辑，改名不会切换当前会话。名称去除首尾空白后提交，最长 100 字，空名称不能保存；名称未改变时直接退出编辑，不发送请求。保存成功同步更新会话列表与对应详情缓存，失败保留输入供重试；回车与失焦连续发生时只提交一次。

点击删除发送 `DELETE /api/generation-sessions/{sessionId}`，请求期间禁用该条目的操作菜单并显示加载状态；收到 204 后移除会话，保留图片、作品和额度记录。删除当前会话回到新对话页并替换当前路由，删除其他会话不改变当前内容。活动创作或图片任务导致 409 时显示服务端原因；网络等错误显示重试提示，失败不会移除历史。

Agent 回复按四个区域布局：

1. AI 思考过程：每次模型调用的公开文字，以及工具名称与执行状态。过程区可折叠；运行时默认展开，用户仍可收起。工具条目保留原有卡片样式，不能点击展开；REST 和 SSE 均不传工具参数、完整路径或返回正文。Skill 通过简短 skillName 显示中文名称。
2. 表单操作：待回答表单可填写、跳过或取消；已处理卡片默认折叠，展开查看已填写值、跳过或取消说明。
3. AI 最终回复：仅展示投影标记为 final 的末条完成回复，不与过程文字重复。
4. 图片展示区域：按 assetId 去重的横向图片卡片，保留查看、下载、复制、收藏、发布及删除。

这里的思考过程是公开工作记录，不展示模型隐藏 thinking。普通生成展示状态与图片，不补写不存在的 Agent 文字。

过程区将连续同类的文生图、图生图、查看参考图片调用合并为一行，保留工具卡片样式；仅在多次调用时显示“成功调用数/已发起调用总数”。例如两次文生图调用全部成功显示“文生图（2/2）”；一次调用生成两张图仍是单次调用，不显示该计数。分母随新调用增长，不预估后续工具或图片数量。

分组限于同一次创作，遇到过程文字、表单、最终回复或其他工具立即结束，generation 图片项不打断分组。读取 Skill 和请求用户确认逐次展示。组内仍有 RUNNING 时显示执行中，失败或取消次数同时保留；终态保留失败、取消信息，不能用最后一次成功覆盖前面的失败。工具调用记录不合并进缓存、不删除，刷新历史后使用相同规则生成工具行。

活动轮次禁用新提交，提供停止；WAITING_INPUT 启用原表单卡片。提交和跳过在同一轮继续，展示提交后的字段值。30 轮通过服务端 creationCount/creationLimit 判断，前端按钮不是唯一限制。

创作运行与图片排队是不同状态：Agent 可以继续显示过程，图片项独立显示 QUEUED、RUNNING 和终态。普通生成使用同样的图片项。后端从持久化图片执行记录补全历史，取消 Agent 后已经发出的生图仍可完成，刷新后保留真实图片结果；前端不根据创作结束推断图片一定失败。

点击图片读取资产详情并使用 ImageDetailShell：吸顶工具栏左侧提供下载，右侧为收藏与更多菜单，发布、复制和删除收在菜单中。信息区展示正负提示词、尺寸、生成数量和生成时间，仅已公开图片展示标题与描述。删除将缓存中的会话引用置为不可用，不移除聊天文字。滚动接近底部时跟随新内容，用户上翻时不强制拉回。

编辑器展开和收起都使用 20px 圆角，发送按钮分别为 40px、48px；模式与“设置”共用 36px 高的工具栏控件，设置面板向上展开。每轮末尾不再提供自动带入图片和预设文案的快捷续作按钮；下一轮通过编辑器手动输入、添加参考图提交。模式偏好保存在 sessionStorage，提示词和参考图不通过初始草稿属性跨轮注入。

## 6. API、前端模型与状态管理

协议见 [创作通信协议](../../architecture/creation-protocol.md)。`entities/generation/model/session.ts` 定义 SessionSummary、SessionDetail、CreationTurn 和四种 SessionItem。

缓存键为 `[generation,sessions]`、`[generation,session,sessionId]`。创建响应直接将新 turn 放入会话缓存，仅刷新侧栏摘要；已有会话切换复用缓存。会话详情 staleTime=Infinity，SSE 重连主动刷新一次。

会话删除成功后取消列表及目标详情的在途查询，移除列表项和目标详情缓存，并清除对应事件缓冲及完成/失败提示。当前 QueryClient 记录已删除会话 ID，拒绝其迟到 SSE，避免恢复内容或通知；不影响其他会话，登出时清空这些临时标记。

- creation.updated 更新 status/revision，忽略较旧版本。
- creation.item.upserted 按 item.id 更新完整内容，文本无需按 delta 重放。TS 每 100ms 合并同条目的更新，依次发送累计全文；前端替换/合并当前文字，仍持续流式展示，不等待回答全部结束。
- 事件先到、创建 HTTP 后到时，由 session-events 缓冲再合并。
- 历史响应迟到时保留更完整文本、final 分类、工具终态、较新执行状态和已解决表单。
- 断线重连通过完整历史对账；用户登出清空临时事件。
- 生图结果到达后使资产列表失效，资源管理操作局部更新已有缓存。

## 7. 组件与实现位置

- generate-workspace.tsx：侧栏、会话查询、滚动、请求与图片详情编排。
- session-history-item.tsx：侧栏会话选择、状态提示、名称编辑及删除请求；改名同步缓存，删除成功交由工作台清理状态和路由，失败原位提示。
- conversation-turn.tsx：用户需求、四区回复与创作状态。
- agent-process.tsx：可折叠的公开过程文字与工具状态列表，工具条目不含展开交互或详情。
- agent-activity-presentation.ts：从原始 items 派生连续同类工具组、调用计数与汇总状态，不修改 SessionDetail 或传输协议。
- generation-image-card.tsx：图片加载、重试和资产操作。
- generation-composer.tsx：普通/Agent 参数输入及统一创建响应处理。
- generation-api.ts：REST 请求和查询键。
- session-events.ts：提前事件缓冲、创建响应和快照合并。
- generation-event-stream-provider.tsx / parsing.ts：用户级 SSE 连接和事件解析。
- agent-input-form-card.tsx：直接使用 SessionFormItem，展示待填写表单或已处理折叠记录；无需额外包装模型。
- ImageDetailShell、OwnedImageDetailActions：复用图片详情和操作视图。

## 8. 异常场景、可靠性与安全

失败状态不清空已展示消息。SSE 不可用时可重连并读取历史；POST 响应未知不自动重放付费创作。图片首次加载失败后请求单图刷新，最多自动重试一次。签名 URL 只存在内存，不写 localStorage。

## 9. 测试与验收

运行 `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm build`。核心用例覆盖四区分离、过程与表单折叠、工具无展开详情、连续同类工具分组与调用计数、文字/表单/其他工具的分组边界、混合成功失败及取消状态、实时与历史投影一致、填写/跳过/取消状态、图片排队与执行状态、SSE 不触发每帧历史请求、旧响应不回退 final 或终态、API 表单只提交值和 30 轮构造边界；会话改名校验、删除的 204 空响应、当前/其他会话删除、失败保留与重试、迟到事件过滤和登出清理。

回归运行单元/组件测试、typecheck、lint 和生产构建；用例数量以当前命令输出为准。普通与带表单 Agent 的真实生成用于验证实际链路，桌面和手机视口核对四区、图片加载及刷新一致性；图片排队、取消、重复事件和故障恢复通过自动化构造验证，不为每个分支重复付费调用模型。一次性截图、账号及脚手架验收后清理，凭证不写入文档。

## 10. 后续边界

不增加历史分页、独立实时状态仓库、浏览器持久化会话文件或每帧服务端重查。超大历史通过会话上限控制，必要时再评估虚拟列表。
