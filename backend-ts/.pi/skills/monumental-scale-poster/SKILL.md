# 巨物尺度清透海报

把任意主题转译为“上方巨物压近 + 中部明亮呼吸带 + 微小尺度标记 + 下方透明反射介质 + 清透现代文字层”的单画布高概念海报。Skill 负责这套视觉结构和主题转译；系统提示词负责通用交互，Tool Schema 和 Harness 负责画幅、数量、素材授权与错误等硬约束。

## 一、任务边界

- 用户要求单张视觉海报、电影海报、品牌主视觉、音乐或社媒封面、活动海报、书封或概念图时，可以使用本 Skill。
- 用户只需要文案或设计建议时直接回答，不调用生成工具。
- 不处理复杂视频分镜、多镜头叙事、写实商品详情页套图、长图或高密度信息排版。
- 这不是普通电影海报，也不是把主题物体机械放大。所有主题都必须重新派生巨物主形体、尺度标记、反射介质和色彩系统，同时保持固定的第一视觉关系。
- 默认交付一个单画布方向；同一方向需要多个变体时使用一次 Tool Call 的 `imageCount`，不把变体误做成拼贴或多套无关构图。

## 二、需求确认与表单

主题是唯一不可缺少的语义输入：

- 用户已经明确主题或自定义对象时，直接继续，不强制弹出表单。
- 用户只说“做一张巨物尺度清透海报”而没有主题时，调用 `request_user_input` 引导选择主题，不要静默把“爱情”当成最终主题。
- 用途、文字模式和色彩情绪没有明确时，可以从请求合理判断；只有缺失项会实质改变结果且无法可靠判断时，才随主题一起询问。
- 画幅由用户请求和 Runtime 的 Creation 约束决定，不放入表单建立第二个事实源。

需要表单时只加入尚未明确的字段，总数不得超过现有 Tool 上限。可按需使用：

- `subject`：`SINGLE_SELECT`，建议项 `LOVE`、`SOLITUDE`、`SUMMER`、`FAREWELL`、`SCI_FI`、`CHINESE_STYLE`、`GROWTH`、`PRODUCT`，必须允许自定义；可以把最合理建议设为初始值。
- `purpose`：`CONCEPT_POSTER`、`FILM_POSTER`、`BRAND_KEY_VISUAL`、`MUSIC_COVER`、`EVENT_POSTER`、`BOOK_COVER`、`SOCIAL_COVER`，允许自定义。
- `textMode`：`WITH_TEXT` / `NO_TEXT`。
- `title`、`subtitle`、`auxiliaryInfo`：可选文本；无文字版保持为空。
- `colorMood`：`COOL_CLEAR`、`WARM_GENTLE`、`SUMMER_BRIGHT`、`MYSTERIOUS`、`BRAND_COLOR`、`AUTO`，允许自定义。
- `scaleMarker`：`PERSON`、`BOAT`、`BIRD`、`LETTER`、`VEHICLE`、`RING`、`MINI_PRODUCT`、`AUTO`，允许自定义。

已有内容要作为初始值，不让用户重新填写。用户跳过时，保留已知事实并由模型决定普通设计选择，不立即重复询问。表单不能修改 Runtime 画幅和图片数量，也不能上传图片或授予 Asset 权限。

## 三、先做主题视觉转译

在内部建立一份简短映射，不把它机械展示给用户：

1. **材质语义**：主题最可信的物理材质、表面、重量、透明度和运动方式。
2. **情绪语义**：主题需要的距离感、压迫感、轻盈度、宁静度或张力。
3. **文化与季节语义**：只有确实相关时，提取地域、季节、仪式或品牌线索。
4. **巨物主形体**：由前三项派生，决定从上方压近的巨大结构。
5. **尺度标记**：选择一个极小但可读的载体，说明巨物有多大，同时参与主题叙事。
6. **反射介质**：选择能承接主形体、光源和倒影的透明或半透明表面。
7. **色彩系统**：主透光底色、低饱和支持色、克制强调色和必要的信息文字色。

主题映射可以参考但不能照抄：爱情可转译为半透明花瓣、信纸褶皱和两个人影；孤独可转译为垂落窗帘、单人和夜水；夏天可转译为透明冰层、游泳者和清水；离别可转译为站台顶棚、远行者和雨湿地面；科幻可转译为透明环形结构、探测器和镜面液体；国风可转译为宣纸山体、孤舟和雨后石面；产品可放大其真实材质，并以微型产品或人物建立尺度。每次都要依据当前主题重新判断，不能把所有主题变成花瓣、布幕、云或山体。

## 四、固定第一视觉结构

以下五层关系必须同时成立，但应根据画幅调整占比和方向，不能套成僵硬模板。

### 1. 上方巨物压近

主题派生的主形体从画面上方压近，占据最大视觉重量。它可以柔软垂落、弯曲覆盖或形成具有材料逻辑的巨大边缘，必须有可信纹理、厚度、透光或表面变化。巨物边缘形成连续遮蔽和窄缝透光，不能只是普通主体居中放大。

### 2. 中部明亮呼吸带

中部保留一条干净、明亮、空旷的呼吸带。它是巨物与下方空间之间的光学间隙，也是全图最重要的留白和透光区域。不得被复杂背景、装饰粒子或文字填满。

### 3. 微小尺度标记

一个主题相关的人物、载体或微型物件安静穿过或停留在呼吸带附近。它必须明显小于巨物，并与主题存在叙事关系；不要添加多个同等醒目的小物，也不要让尺度标记变成第二主角。

### 4. 下方透明反射介质

使用水面、玻璃、薄冰、镜面液体、潮湿地面、透明树脂或亚克力等介质承接巨物和光源。介质需要透明、反光并有轻微物理变化，让倒影被拉长、散开或轻微折射；不能用一块无物理关系的镜面贴图代替。

### 5. 柔焦前景与空气层

前景逐渐变深并保持柔焦，光雾或水汽只用于连接空间层次，不能遮蔽主题。最终空间像被透光空气托住，清透明亮而非烟雾浓重。

## 五、色彩和文字

### 色彩

- 从主题材质、季节、情绪、文化或品牌语义提炼色彩，不使用固定通用色卡。
- 建立大面积高明度透光底色、一个低饱和支持色和少量克制强调色；信息文字色可以有对比，但不能刺眼。
- 保持清透、安静、明亮洁净和透明层次，避免灰黄旧化、脏颗粒、厚重暗黑、重 HDR 和油腻高光。

### 文字

- 用户选择无文字时，在 Prompt 中明确“无文字、无标题、无字幕、无水印”。
- 用户提供准确标题、副标题或辅助信息时逐字使用，不改写、不翻译，也不虚构日期、地点、导演、品牌、奖项或其他事实。
- 用户允许模型生成文字时，只生成一个极简标题和至多一句短副标题；辅助信息没有事实来源时不添加。
- 文字是稀疏、轻薄、宽字距的现代信息层。主标题可以大但应色浅、轻盈并保留空白；副信息更小、更集中，靠近画面边缘或呼吸带下方。
- 文字悬浮在反射空间前，不能横跨最亮窄缝、遮挡尺度标记或压过巨物第一视觉。禁止大段文字、大红大金粗字、促销综艺字体和高密度栏目。

## 六、图片路径和画幅

当前请求直接附带的图片已经提供给模型，同时 Runtime 会注入本轮允许使用的 Asset ID：

- 不依赖图片创建全新主题海报：使用 `text_to_image`。
- 当前请求已授权的主体轮廓、产品、材质或品牌色必须保留并参与画面：使用 `image_to_image`。
- 图片只提供抽象灵感而不需要保留视觉身份：提炼必要特征后使用 `text_to_image`，不要机械套用图生图。
- Context 中只有历史 Asset ID 且确实需要理解图片：先使用 `inspect_image`；若它必须成为图生图输入，请用户在当前请求重新选择，不能绕过授权。

当前生成 Tool 只接受 `1:1`、`4:3`、`3:4`、`16:9` 和 `9:16`：

- 用户或 Runtime 指定支持比例时严格服从。
- Runtime 为自动且用户没有指定时，概念海报和电影海报优先 `16:9`，书封或竖版活动海报优先 `3:4`，社媒方图可以使用 `1:1`。
- 用户要求 `4:5`、`21:9` 或其他不支持比例时，不静默替换、不画内加边伪造；说明当前支持范围并请用户选择后重新生成。

## 七、编译并执行 Prompt

按以下顺序写成一段完整、自然、可执行且不超过 Tool 长度上限的 Prompt：

1. 当前主题、用途和准确画幅。
2. 主题派生的上方巨物主形体：材料、形态、纹理、重量、透光和压近关系。
3. 巨物边缘的连续遮蔽、窄缝透光和中部明亮呼吸带。
4. 一个微小尺度标记的位置、动作及其与主题的关系。
5. 下方透明反射介质、光源承接、拉长倒影和轻微波动或折射。
6. 前景渐深、柔焦和克制的空气层。
7. 来自主题的高明度底色、低饱和支持色、克制强调色和实际光源。
8. 准确文字内容、层级、字形气质、位置和留白；无文字时明确排除全部文字。
9. 当前任务最重要的负向约束，例如普通主体居中海报、没有尺度反差、无反射介质、浑浊旧化、脏颗粒、厚重暗黑、信息堆满、文字喧宾夺主和廉价模板排版。

生成时使用一个视觉方向和一次 Tool Call；同方向多个变体通过 `imageCount` 完成，并服从 Creation 的图片总数。调用前输出一至两句安全创作说明，并把同一段内容写入 `userFacingPlan`。Tool 返回失败时根据模型可见错误修正参数，不得绕过画幅、数量或素材授权。

## 八、生成前检查

- [ ] 主题已明确，巨物、尺度标记、反射介质和色彩都由主题合理派生。
- [ ] 上方巨物占据最大视觉重量，而不是普通主体居中放大。
- [ ] 中部存在干净明亮的呼吸带和窄缝透光。
- [ ] 只有一个微小尺度标记，并形成一眼可读的巨大反差。
- [ ] 下方透明介质与巨物、光源和倒影存在可信物理关系。
- [ ] 前景柔焦和空气层克制，没有变成厚重烟雾。
- [ ] 色彩清透明亮，没有浑浊旧化、油腻高光或脏颗粒。
- [ ] 文字内容和授权准确，排版服从第一视觉；无文字版没有残留字符。
- [ ] Tool、图片授权、画幅和图片数量符合 Runtime 约束。
- [ ] 结果不是普通电影海报、促销模板、商品详情页或高密度信息设计。
