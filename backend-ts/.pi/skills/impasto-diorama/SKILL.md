# 油彩立体厚涂风

把照片转译为“真实摄影 × 油画刀厚涂 × 立体微缩场景 × 大面积纸面留白 × 高级编辑排版”的独立作品。Skill 负责厚涂转译方法；系统提示词负责通用交互，Tool Schema 和 Harness 负责素材授权、画幅、数量、取消与错误等硬约束。

## 一、任务边界与交付方式

- 本 Skill 必须以当前请求已授权的照片为输入，并使用 `image_to_image`；没有照片时，请用户先上传或重新选择照片，不要改用 `text_to_image` 猜测原图。
- 用户上传多张照片时，每张照片分别制作一张独立作品：每张只绑定一个 `inputAssetId`，分别调用一次 `image_to_image`，每次 `imageCount` 为 `1`。不得把多张照片拼进同一张画布，也不得把一张照片拆成多张无关结果。
- 用户或 Runtime 指定的图片总数属于硬约束。若总数与需要逐张处理的照片数量冲突，不得静默漏图、拼图或重复图片；说明冲突并请用户以匹配数量或“自动”重新发起请求。
- 默认成品为 `3:4` 竖版上下双联：上半部分是真实摄影，下半部分是厚涂立体微景观。只有在 Runtime 画幅为自动时才采用 `3:4`；用户或 Runtime 已指定其他受支持画幅时，服从该画幅并重新安排上下比例，不改变厚涂转译美学。
- 用户或受信任 Runtime 上下文明确指定其他成品容器时，只替换版式容器和画幅；照片保真、厚涂转译、纸面留白、配色和文字原则仍然适用。
- 当前图生图是生成式重构，可以要求高度保留身份和结构，但不能承诺原照片像素级不变。若用户必须原图逐像素保留，应先说明当前能力边界，不把生成结果描述成精确合成。

## 二、只确认真正阻塞的信息

照片齐全、用户直接要求这种风格时，不调用 `request_user_input`，立即完成设计并生成。仅在以下未决信息会改变交付事实时暂停确认：

- 用户上传多张照片，却只要求处理其中一部分，而具体选择无法确定。
- 用户提供文字但无法判断应逐字保留、只作为主题参考，还是不在成品中出现。
- 用户明确要求非默认成品结构，但上下双联、全画布厚涂或其他容器之间存在冲突。

表单只加入尚未解决的字段，可以按需使用：

- `selectedPhotos`：要处理的照片名称或顺序，仅用于解决明确的选择歧义；不要向用户展示内部 Asset ID。
- `copyMode`：`NO_TEXT`（不加文字）/ `AUTO_TITLE`（根据照片生成标题）/ `VERBATIM`（逐字使用用户文案）。
- `requiredCopy`：必须逐字出现的文案，把已经识别出的文字作为初始值。
- `layoutMode`：`DOUBLE_PANEL`（摄影与厚涂双联）/ `FULL_CANVAS`（在其他容器中保持摄影与厚涂关系），仅在用户要求确实不明确时询问。

表单不能上传照片、授予 Asset 权限，也不能修改 Creation 的画幅或总数量硬约束。用户跳过后，保留已知事实，对非关键版式和文字采用合理默认值，不立即重复询问。

## 三、保留真实摄影区域

- 保留原始照片最具识别性的主体身份、结构、姿态、空间关系、真实材质、自然光影和原有色彩氛围。
- 只进行轻微且统一的高级摄影调色，不用风格滤镜覆盖真实摄影。
- 为适配画幅，可以自然延展环境背景，但不得拉伸、扭曲、镜像或改变主体。
- 先识别原图中必须保留的主体、动作、关系、地点线索和情绪，再决定上下双联的裁切、衔接和留白。

## 四、重构厚涂立体微景观

设计区域先理解照片中最具识别性的主体、动作、关系和情绪，再把它重构为嵌入厚涂颜料中的立体微缩场景：

- 主体以可触摸的微型实体、浮雕或雕塑性绘画形态出现，保留一眼可辨的身份和关键叙事关系。
- 删除无关背景和细碎信息；细节集中在识别所必需的位置，其余部分可以融入笔触、被颜料吞没或在边缘自然消散。
- 主体必须真正长在颜料之中，与颜料发生承托、嵌入、覆盖、堆叠、陷落或延伸关系，不能把完整场景贴进矩形画框。
- 不得把主体概括成扁平几何图标，也不得做成普通滤镜转绘、光滑塑料 3D、卡通玩具或完整场景复刻。

## 五、建立真实厚涂与纸面

- 以暖白、象牙白或自然纸白的粗纹理纸面形成大面积留白。
- 在纸面上建立一块具有明确方向性的不规则颜料岛，例如斜向色带、被刮开的色块、带撕裂感的长形笔触或自然扩散的颜料地形。
- 颜料应有真实油画刀厚涂特征：堆积、刮痕、脊线、断裂边缘、露底、层层覆盖、局部高光，以及由颜料厚度形成的柔和投影。
- 主体自身也具有厚涂塑形与微缩雕塑的体积感，不能悬浮在颜料之外。
- 避免普通水彩晕染、规整几何拼贴、无关装饰性泼墨和均匀铺满画面的纹理。

## 六、配色与构图

- 从原始照片最有辨识度、最有情绪力量的颜色关系中提炼配色，不使用固定通用色卡。
- 选择一个主导厚涂色域，再以少量深色结构色、纸面中性色和关键亮色塑造主体。颜色可以浓郁、明亮或克制，但必须与原图气氛和主体身份相关。
- 构图只保留一个厚涂视觉锚点、一个核心微缩场景和大面积留白。
- 根据主体走势决定颜料岛的方向、尺度与偏心位置，形成明确的大小反差、轻重关系和呼吸感。
- 辅助元素只保留真正参与原图叙事的少量对象，不建立第二中心，不堆满版面。

## 七、处理文字

- 用户未要求文字时，不为填充版面强行添加标题。
- 用户允许模型生成文字时，根据主体、动作、地点、情绪或隐喻写一个简短而有意味的标题，并只配极少量编辑式小字；不得添加无关说明、模板化栏目、虚构事实或年份。
- 用户提供准确文案并要求保留时，逐字使用，不改写、不翻译、不另加标题。
- 文字语言遵循用户明确指定的语言或地区；排版使用克制的衬线体、细瘦编辑字体或与目标语言相称的精致字形，轻轻进入留白，不压过厚涂主体。

## 八、编译并执行 Prompt

每张照片使用一段独立 Prompt，并按以下顺序组织；只写当前作品需要的内容，控制在 Tool 的长度限制内：

1. 成品类型、准确画幅和摄影/厚涂的容器关系。
2. 原图中必须保留的主体身份、姿态、关系、空间、材质、光影与色彩。
3. 真实摄影区域的裁切、背景延展和轻微调色边界。
4. 厚涂微缩区域的核心主体、叙事动作及其与颜料的物理关系。
5. 纸面、颜料岛方向、油画刀堆积、边缘、层次、高光和厚度投影。
6. 从原图提炼的主色域、结构色、中性色和关键亮色。
7. 一个视觉锚点、大面积留白、尺度反差和必要的编辑文字。
8. 当前作品最重要的排除项，例如多图拼接、塑料 3D、扁平图标、水彩晕染、几何模板和无意义泼墨。

每张照片分别调用：

- Tool：`image_to_image`
- `inputAssetIds`：只包含该照片对应的一个本轮授权 Asset ID
- `imageCount`：`1`
- `aspectRatio`：严格服从 Runtime；自动时使用 `3:4`
- `userFacingPlan`：用一段简短文字说明将如何保留照片主体并进行厚涂微景观转译，同批照片保持同一总体表达，不重复输出相同说明

## 九、生成前检查

- [ ] 当前请求至少有一张已授权照片，且没有绕过权限使用历史 Asset ID。
- [ ] 每张照片独立生成，没有多图拼接、漏图或重复图片。
- [ ] 图片总数和画幅符合 Runtime 硬约束。
- [ ] 真实摄影区域保留身份、结构、姿态、关系、材质、光影和原有气氛。
- [ ] 厚涂主体是一眼可辨的立体微缩叙事，不是滤镜、图标或光滑塑料模型。
- [ ] 主体真正嵌入颜料，厚度、刮痕、边缘、覆盖和投影具有物理可信度。
- [ ] 配色来自原图，一个视觉锚点与大面积纸面留白成立。
- [ ] 准确文案逐字保留；模型文案简短、有意义且不虚构事实。
- [ ] Prompt、输入照片、画幅、文字和结果数量彼此一致。

工具返回参数、权限或业务错误时，根据模型可见的 Tool Result 修正可纠正问题；不得移除必要照片、放宽用户硬约束、改用文生图或把失败结果说成已经完成。
